The Reparameterization Trick

Lesson Objectives

What you will learn

Understand why sampling breaks backpropagation in VAEs and how the reparameterization trick ($z = \mu + \sigma \cdot \epsilon$) restores gradient flow.

Prerequisites

Understanding of backpropagation and gradient descent. VAE loss function from Lesson 10.6.

Expected Outcome

Explain the gradient blocking problem caused by stochastic sampling, draw the reparameterization trick computation graph, and implement the sampling layer conceptually.

Lesson 10.5: The Reparameterization Trick

The Problem: Sampling Blocks Gradients

In a VAE, the latent vector $z$ is sampled from the distribution predicted by the encoder:

z \sim \mathcal{N}(\mu, \sigma^2)

For backpropagation to work, every operation in the network must be differentiable. However, sampling is a stochastic (random) operationâ€”it has no defined derivative. The gradient signal cannot flow backward through the sampling node, effectively blocking the encoder from learning via gradient descent.

Key Problem: The gradient of a random operation is undefined. Without a workaround, the encoder cannot learn to adjust $\mu$ and $\sigma$ using gradient descent.

The Solution: Reparameterization Trick

The reparameterization trick isolates the random sampling step. Instead of sampling $z$ directly from $\mathcal{N}(\mu, \sigma^2)$, we:

  1. Sample a noise vector $\epsilon$ from a standard normal distribution (which does not depend on the model parameters):
\epsilon \sim \mathcal{N}(0, I)
  1. Compute $z$ deterministically using a linear transformation:
z = \mu + \sigma \odot \epsilon

Here, $\odot$ represents element-wise multiplication. Because the network's trainable parameters ($\mu$ and $\sigma$) now appear in a simple linear equation, gradients can flow freely through them during backpropagation.

Why This Works

  • The randomness is now isolated in $\epsilon$, which is an external input to the network, not an internal operation.
  • The expression $z = \mu + \sigma \cdot \epsilon$ is fully differentiable with respect to $\mu$ and $\sigma$.
  • The gradient $\frac{\partial L}{\partial \mu}$ and $\frac{\partial L}{\partial \sigma}$ can be computed and used to update the encoder weights.
💡
Intuition: Think of it as "outsourcing" the randomness. Instead of the network doing something non-differentiable (sampling), we feed it pre-sampled noise and let it learn how to scale and shift that noise using differentiable parameters.
