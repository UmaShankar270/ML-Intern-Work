When to Use / When Not to Use

Use Autoencoders/VAEs When:

  • You need to learn non-linear patterns that PCA cannot capture.
  • You are performing unsupervised representation learning or self-supervised pre-training.
  • You want to build anomaly detection systems (flagging inputs with high reconstruction error).
  • You want to generate new, synthetic data samples (use VAE).

Do NOT Use When:

  • You have a small dataset (neural networks need lots of samples to generalize well).
  • You need perfectly interpretable features (latent dimensions are abstract).
  • You need lossless, exact data compression (traditional JPEG/PNG or linear PCA is faster and more reliable).

Lesson 10.8: Module Summary

Key Takeaways

  • Autoencoders compress data by feeding it through an encoder, bottleneck, and decoder, minimizing reconstruction error. The encoder compresses, the bottleneck holds the compact representation, and the decoder reconstructs.
  • Traditional autoencoders have fragmented latent spacesâ€”there are gaps between class clusters where the decoder outputs meaningless noise. This prevents them from generating new data by sampling from latent coordinates.
  • VAEs solve this by mapping inputs to probability distributions (mean $\mu$ and variance $\sigma^2$) rather than deterministic points. The KL divergence regularization term forces the distributions to overlap, creating a continuous, well-structured latent space.
  • The reparameterization trick makes sampling differentiable by computing $z = \mu + \sigma \odot \epsilon$ where $\epsilon \sim \mathcal{N}(0, I)$. This shifts the stochasticity to an external noise source, allowing gradients to flow through $\mu$ and $\sigma$ during backpropagation.
  • VAEs are evaluated on three criteria: reconstruction accuracy (how well the output matches the input), latent space visual separation (whether classes form distinct clusters), and latent interpolation smoothness (whether interpolating between coordinates produces realistic intermediate samples).
💡
Final Thought: If you only need compression, use a traditional autoencoder. If you need to generate new data like the training distribution, use a VAE. If you need fast, interpretable, linear dimensionality reduction, use PCA.
