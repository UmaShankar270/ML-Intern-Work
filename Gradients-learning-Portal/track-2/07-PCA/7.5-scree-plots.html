Explained Variance & Scree Plots

Lesson Objectives

What you will learn

Understand how to interpret scree plots, explained variance ratios, and the elbow method to select the optimal number of principal components.

Prerequisites

Understanding of eigenvalues as variance captured per component from Lesson 7.2.

Expected Outcome

Read a scree plot, apply the elbow method, and choose $k$ using the 95% explained variance threshold for any PCA pipeline.

What is a Scree Plot?

A scree plot is a line plot that shows the explained variance (eigenvalue) of each principal component, sorted from largest to smallest. It visually communicates how much information each component contributes and helps you decide how many components to retain.

Explained Variance Ratio (EVR)

After eigendecomposition, each component $i$ captures a fraction of the total dataset variance:

\text{EVR}_i = \frac{\lambda_i}{\sum_{j=1}^{d} \lambda_j}

The cumulative explained variance is the running sum: $\sum_{j=1}^{k} \text{EVR}_j$. This tells you how much total variance is retained when keeping the top $k$ components.

Method 1: The Elbow Method

Look for the point where the curve flattens out â€” this is the "elbow." Components after the elbow contribute relatively little additional variance.

  • In the diagram above, the elbow is at PC2: PC1 contributes 36%, PC2 adds 19%, but PC3 through PC5 each add under 11%.
  • Choose $k$ at the elbow for maximum compression with minimal information loss.

Method 2: Cumulative Variance Threshold

Select $k$ such that the cumulative explained variance exceeds a target threshold:

  • 95% threshold â€” standard for most modeling tasks (retain 95% of signal).
  • 99% threshold â€” used when reconstruction fidelity is critical.
  • 70-90% â€” acceptable for exploratory analysis and visualization.
