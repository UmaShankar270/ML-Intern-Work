Encoding Categorical Variables

Most machine learning models require numerical input. Categorical variables â€” data that takes a limited number of discrete values (e.g., colors, countries, departments) â€” must be converted into numerical representations before they can be used by an algorithm. This process is called encoding.

Key Insight: The choice of encoding method directly impacts model performance. A poor encoding can introduce misleading ordinal relationships or create excessive dimensionality.

1. One-Hot Encoding

One-Hot Encoding creates a separate binary column for each category. For a categorical variable with $k$ unique values, it generates $k$ new columns, where exactly one column is "hot" (set to 1) for each row.

Example: Fruit Color Encoding

2. Label Encoding

Label Encoding assigns a unique integer to each category. The values are 0, 1, 2, ..., $k-1$ for $k$ categories.

Example:

London1

Caution: Label encoding implies an artificial ordinal relationship (e.g., Tokyo > London). This can mislead linear models. Reserve label encoding for ordinal categorical variables or tree-based models.

3. Ordinal Encoding

Ordinal Encoding is specifically designed for ordinal categorical variables â€” categories with a natural order (e.g., education level: High School < Bachelor's < Master's < PhD).
