3. Elastic Net

Elastic Net combines both L1 and L2 penalties, balancing Lasso's feature selection with Ridge's stability when features are highly correlated.

\text{Cost} = \text{Loss} + \lambda_1 \sum_{j=1}^{d} |w_j| + \lambda_2 \sum_{j=1}^{d} w_j^2

Where $\lambda_1$ controls the L1 penalty strength and $\lambda_2$ controls the L2 penalty strength. In Scikit-learn, this is parameterized via alpha (total penalty) and l1_ratio (mixing proportion).

L1 vs. L2 vs. Elastic Net: Comparison

PropertyLasso (L1)Ridge (L2)Elastic Net
Penalty Term$\sum |w_j|$$\sum w_j^2$$\lambda_1 \sum |w_j| + \lambda_2 \sum w_j^2$
Feature SelectionYes (zero weights)No (all weights kept)Yes (sparsity + grouping)
Handles Correlated FeaturesSelects one randomlyKeeps all, shrinks togetherGroups correlated features
DifferentiabilityNot at zero (subgradients)Fully differentiableMixed (subgradient methods)
Best Used WhenSparse solution neededAll features contributeCorrelated features + sparsity
💡
When to Use Elastic Net: If you have a dataset with many correlated features (e.g., gene expression data), Lasso may arbitrarily select one feature from a correlated group. Elastic Net maintains stability by grouping them, while still performing feature selection through the L1 component.
