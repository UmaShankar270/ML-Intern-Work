L2 Regularization (Ridge)

Lesson Objectives

What you will learn

  • Write and explain the Ridge (L2) cost function formula.
  • Understand how L2 regularization shrinks all weights smoothly toward zero.
  • Compute a worked Ridge cost calculation example.
  • Compare overfit vs. regularized models visually.

Prerequisites

Completion of previous conceptual lessons in this track.

Expected Outcome

Implement L2 penalized cost computations and explain why Ridge retains all features while reducing their influence.

1. Ridge Regression (L2 Regularization)

L2 regularization penalizes the sum of the squared weights. It shrinks all weights toward zero but rarely makes them exactly zero.

\text{Cost} = \text{Loss} + \lambda \sum_{j=1}^{d} w_j^2

Variable Descriptions:

SymbolMathematical RepresentationConceptual Meaning
$\text{Loss}$Scalar (e.g., MSE)The prediction error on training data.
$\lambda$Real number ($\lambda \ge 0$)Regularization strength parameter. Higher means stronger penalty.
$w_j$ScalarThe weight coefficient of the $j$-th feature.
$\sum w_j^2$ScalarThe L2 norm penalty, summing the squared weights.

Ridge (L2) Cost Calculation: Worked Example

Suppose we have a model with two weights $w_1 = 3.0$ and $w_2 = 0.5$, a prediction error of $\text{Loss} = 2.0$, and regularization strength $\lambda = 0.1$.

\text{Penalty}_{\text{L2}} = \lambda (w_1^2 + w_2^2)
\text{Penalty}_{\text{L2}} = 0.1 \cdot (3.0^2 + 0.5^2) = 0.1 \cdot (9.0 + 0.25) = 0.1 \cdot 9.25 = \mathbf{0.925}
\text{Cost}_{\text{Ridge}} = \text{Loss} + \text{Penalty}_{\text{L2}} = 2.0 + 0.925 = \mathbf{2.925}

The Optimizer's Perspective

Suppose the optimizer considers reducing $w_1$ from $3.0$ to $2.0$. Under L2, the penalty drops from $0.1 \cdot 9.0 = 0.9$ to $0.1 \cdot 4.0 = 0.4$, saving $0.5$ in cost. Ridge penalizes large weights aggressively, encouraging them to stay small.

💡
Key Comparison: For the same weight reduction ($3.0 \to 2.0$), L2 saves $0.5$ in penalty cost while L1 saves only $0.1$. This is why Ridge shrinks large weights faster than Lasso, but Lasso can push weights all the way to zero.
